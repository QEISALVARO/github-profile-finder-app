(PostgreSQL 17.11, pgTAP 1.3.3, pg_trgm, pgcrypto, unaccent), port host 54322.

`supabase start` tidak dapat dipakai pada mesin ini (CLI 2.122.0 gagal menyalin
secret file ke Docker 29.9.2; CLI 3.0.0 menolak config lama). Karena itu database

database `postgres` image tersebut, dan default privilege ACL Supabase
(`anon`, `authenticated`, `service_role` pada skema `public`) agar setara
`supabase start`.
